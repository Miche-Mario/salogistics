# SA-Errandlogistics Marketplace

A modern marketplace platform connecting buyers and sellers across Nigeria, Ghana, and Benin Republic.

## Features

- Multi-country support (Nigeria, Ghana, Benin)
- Integrated buyer-seller messaging
- Flexible delivery options
- Secure payment processing
- Mobile-responsive design

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Ant Design
- Framer Motion
- GSAP

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
